# Рядом — маркетплейс объявлений

Первая веб-версия: каталог одобренных объявлений, регистрация и вход через Supabase Auth, отправка объявления на ручную модерацию, просмотр собственных объявлений.

## Настройка
1. В Vercel импортируй этот репозиторий после загрузки файлов.
2. Добавь `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` из Supabase → Project Settings → API Keys.
3. Используй только publishable/anon key в браузере. Никогда не публикуй `service_role` или secret key.
4. SQL находится в `supabase/schema.sql`. Для текущего проекта схема уже применена.

## Запуск
`npm install` затем `npm run dev`.

## Что пока не готово
Модерация пока ручная и требует отдельного защищённого интерфейса; фото вводится ссылкой, а не загружается в Storage; чатовые таблицы созданы, но интерфейса чата ещё нет; Android-приложение, автоматическая модерация и публикация на хостинге — следующие этапы. Перед публичным запуском нужно протестировать RLS и весь поток регистрации/модерации.
